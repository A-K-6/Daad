# AGENTS.md • Instructions for Autonomous Coding Agents

This file contains architectural guidelines, conventions, and operational rules for AI coding assistants working on the **Daad** codebase.

---

## 🛠️ Project Stack & Core Tools

- **Desktop Framework:** [Tauri v2](https://v2.tauri.app) (Rust backend, webview frontend)
- **Package Manager & Runtime:** [Bun](https://bun.sh) (`bun` MUST always be used instead of `npm`, `pnpm`, or `yarn`)
- **Frontend Stack:** React 19 + TypeScript + Vite + Tailwind CSS + Lucide React
- **Telephony Engine:** `sip.js` (v0.21+) over WebSockets (WSS) and WebRTC
- **Audio Synthesizer:** Pure Web Audio API (Zero external `.mp3`/`.wav` assets)
- **Test Runner:** Vitest + React Testing Library (`bun run test`)

---

## 📜 Key Architectural Rules & Invariants

### 1. Package Manager
- **ALWAYS** use `bun` for package management and scripts:
  - Install: `bun install`
  - Add package: `bun add <pkg>` / `bun add -d <pkg>`
  - Run dev: `bun run tauri dev` or `bun run dev`
  - Run tests: `bun run test`
  - Build: `bun run build`

### 2. State Management & React Context
- All SIP and telephony states flow through `SipProvider` in [`src/context/SipContext.tsx`](src/context/SipContext.tsx).
- Do not bypass `SipContext` with raw singletons in UI components without proper lifecycle subscriptions.
- Maintain reactive state subscriptions for:
  - `ConnectionState`: `Disconnected` | `Connecting` | `Registered` | `RegistrationFailed`
  - `CallState`: `Idle` | `Calling` | `Ringing` | `Active` | `Holding`
  - `CallHistory`: Synchronized with `callHistoryService.ts` and `localStorage`.

### 3. Telephony Engine & WebRTC
- **Audio Tracks:** Remote tracks MUST be bound to `<audio id="remoteAudio" autoplay />` via `RTCPeerConnection.ontrack`.
- **Microphone Permissions:** macOS permissions are governed by `NSMicrophoneUsageDescription` in [`src-tauri/Info.plist`](src-tauri/Info.plist).
- **Zero Asset Audio:** All tones (DTMF frequencies, ringback cadence, incoming melody, hangup beeps) are generated by [`soundService.ts`](src/services/soundService.ts) using the Web Audio API. Never add external audio asset dependencies.
- **Teardown & Cleanup:** Every terminated session MUST clean up intervals, release remote audio source objects, and record the call outcome in `callHistoryService`.

### 4. UI Design Philosophy (Anti-AI Slop)
- **Utilitarian / Linear / Raycast Aesthetics:** Dark obsidian palettes (`#090a0f`, `#12131a`), 1px subtle borders (`border-white/[0.08]`), tactile press feedback, and monospaced accents (`SF Pro` / `JetBrains Mono`).
- **Responsive Dual Mode:**
  - Inside Tauri desktop: Renders only the compact 360x600px softphone window.
  - Inside web browser: Renders the responsive landing page with the live working softphone widget side-by-side.

### 5. Automated Testing Invariant
- **100% Passing Tests Required:** Whenever modifying or adding features, run `bun run test` and verify that all test suites pass.
- Write unit tests for new services and React Testing Library component tests for new UI views.

## 🚀 Common Commands

```bash
# Start desktop app
bun run tauri dev

# Run full test suite
bun run test

# Run tests in watch mode
bun run test:watch

# Start web server for local mobile phone testing
bun run dev:phone

# Compile production frontend build
bun run build

# Check Rust backend
cd src-tauri && cargo check
```
